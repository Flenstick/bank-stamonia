# Банк Стамонийской Федерации

Карты граждан, две валюты (МОН и Алтын), переводы между игроками, оплата налогов, казна.
Все балансы лежат на сервере в общей базе — что видит один игрок, видят все.

## Что внутри

```
public/index.html            сайт
netlify/functions/bank.mjs   сервер: вся логика и база
netlify.toml                 настройки Netlify
package.json                 зависимость @netlify/blobs
```

## Как запустить (10 минут)

1. **Залейте папку в GitHub.** Создайте новый репозиторий, закиньте туда все файлы.
   Netlify Drop (перетаскивание папки) здесь не подойдёт — функции работают только из репозитория.

2. **Подключите к Netlify.** Add new site → Import an existing project → GitHub → выберите репозиторий.
   Настройки сборки менять не нужно, всё уже прописано в `netlify.toml`. Жмите Deploy.

3. **Задайте переменные окружения.** Site configuration → Environment variables → Add a variable:

   | Ключ | Значение |
   |---|---|
   | `TREASURER_CODE` | ваш пароль от казны, придумайте посложнее |
   | `DISCORD_WEBHOOK` | ссылка на вебхук канала банка |

   Обе лежат на сервере: в коде страницы их не видно, из браузера не достать.

4. **Передеплойте** — Deploys → Trigger deploy → Deploy site. Готово, сайт живой.

## Как пользоваться

- Игрок открывает карту: ник, Discord, ПИН из 4 цифр. Баланс — 0.
- Вы заходите во вкладку **Казна**, вводите `TREASURER_CODE` и начисляете деньги на любую карту.
  Отрицательная сумма = списание штрафа в пользу казны.
- Игроки переводят друг другу по нику или номеру карты, платят налоги по номеру квитанции, меняют МОН на Алтын.
- Карта обновляется каждые 10 секунд сама, страницу перезагружать не надо.
- Каждая операция уходит в Discord отдельным сообщением.

## Что можно поменять

| Что | Где |
|---|---|
| Курс обмена (сейчас 1 МОН = 8 Алтын) | `RATE` в `bank.mjs` **и** в `index.html` — должны совпадать |
| Часовой пояс времени в истории (сейчас UTC+3) | функция `stamp()` в `bank.mjs` |
| Название банка, тексты | `index.html` |

## Полезно знать

- **ПИНы хранятся в виде хэша**, в открытом виде их нет даже у вас. Если игрок забыл ПИН — казначей
  может задать новый через действие `tre_reset_pin` (кнопки в интерфейсе нет, но функция готова).
- **Бесплатный план Netlify** — 300 кредитов в месяц. Для сервера на несколько десятков игроков
  этого хватает с запасом. Если кредиты кончатся, сайт просто приостановится до следующего месяца,
  счёт вам не выставят.
- **База — один blob.** Если два человека переводят деньги в одну и ту же секунду, теоретически одна
  операция может затереть другую. На игровых масштабах это почти невероятно, но знайте.
- **Резервная копия.** Данные живут в Netlify Blobs. Раз в неделю заглядывайте в казну и сохраняйте
  скриншот таблицы — на случай, если что-то пойдёт не так.
